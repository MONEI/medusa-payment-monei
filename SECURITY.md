# Security policy

## Report a vulnerability

Report a vulnerability privately by email to support@monei.com.

Do not open a public GitHub issue, pull request or discussion for a vulnerability.

## What to include

- The version of `medusa-payment-monei` and of Medusa.
- A description of the problem and what an attacker can do with it.
- The steps to reproduce it, or a proof of concept.
- Your contact details, if you want us to reply.

Do not send live API keys, card data or personal data of buyers. Use a MONEI test mode account to reproduce the problem.
